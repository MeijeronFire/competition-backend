# Prerequisite knowledge
To properly be able to understand this codebase you need to understand a few things about programming in general. It is not too complicated, but there are a few concepts slightly above the purview of a beginner in python. The current list (that will hopefully not be updated too much) is underneath, with useful resources attached

- A basic understanding of object oriented programming (inheritance, composition, etc)

- [typed python](https://mypy.readthedocs.io/en/stable/cheat_sheet_py3.html)

- [python modules](https://docs.python.org/3/tutorial/modules.html)

- [asynchronous programming](https://docs.python.org/3/howto/a-conceptual-overview-of-asyncio.
html#a-conceptual-overview-of-asyncio)

- [websockets](https://en.wikipedia.org/wiki/WebSocket) (only surface-level knoweledge is required)

- [SSE](https://en.wikipedia.org/wiki/Server-sent_events) For our admin dashboard, we use Server Sent Events.

- [jinja2 templating](https://jinja.palletsprojects.com/en/stable/templates/) (only surface-level 
knoweledge is required)

- [pydantic models](https://pydantic.dev/docs/validation/latest/concepts/models/) (only surface-level 
knoweledge is required)

- [FastAPI](https://fastapi.tiangolo.com/learn/) (It is not neccesary to know everything about FastAPI, as most of it is boilerplate)

Note that for only implementing games, the amount of knowledge is far less, really only:

- [typed python](https://mypy.readthedocs.io/en/stable/cheat_sheet_py3.html)

- [pydantic models](https://pydantic.dev/docs/validation/latest/concepts/models/) (only surface-level 
knoweledge is required)

- And maybe [asynchronous programming](https://docs.python.org/3/howto/a-conceptual-overview-of-asyncio.html#a-conceptual-overview-of-asyncio)

If you know understand and are comfortable with all of these concepts, the rest of the code is not too hard to undersand.
